# 📊 HR Analytics Project

## 📝 Overview
This project focuses on **Employee Performance & HR Analytics**. Using Python and data visualization techniques, we analyze key insights related to employees' **age distribution**, **training scores**, **length of service**, and various other HR-related factors.  
The goal is to help organizations make **data-driven HR decisions**.

---

## 📂 Dataset
- **Name**: Employee's Performance for HR Analytics  
- **Format**: CSV    
- **Description**: Contains employee demographic details, training scores, experience, and performance metrics.

---

## 🚀 Technologies Used
- **Python 3**
- **Pandas** → Data manipulation
- **NumPy** → Numerical computations
- **Matplotlib & Seaborn** → Data visualization
- **Jupyter Notebook** → Interactive analysis

---

## 🔍 Key Analysis & Insights
- **Age Distribution** → Understands the age segmentation of employees
- **Training Score Distribution** → Analyzes how employees perform in training sessions
- **Length of Service** → Examines employee retention trends
- **Performance Evaluation** → Identifies patterns in performance metrics

---

## 📊 Visualizations
The project includes multiple data visualizations:
- 📌 Age Distribution Graph

- 📌 Length of Service Trends
- 📌 Performance Score Insights

## ⚡ How to Run the Project

```bash
# Clone the repository
git clone https://github.com/pritam9952/Employee’s Performance for HR Analytics.git

# Navigate to project folder
cd Employee’s Performance for HR Analytics

# Install dependencies
pip install -r requirements.txt

# Open the notebook
jupyter notebook code_book_HR.ipynb
```
